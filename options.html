AO3 Styles Settings

for AO3 Advanced Marker

Live CSS from GitHub

When on, every AO3 page fetches dist/styles.css fresh from the main branch on GitHub and layers it over the bundled copy — so you see your latest pushed CSS on this device without recopying any files. Turn it off when you're not actively testing.

This only refreshes CSS. Content-script (JS) changes still require re-copying the extension files onto the device.

Change this only if you're testing a fork or a different branch.
